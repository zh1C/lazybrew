# lazybrew

A lazy terminal UI for [Homebrew](https://brew.sh), built with [Bubble Tea](https://github.com/charmbracelet/bubbletea).

## Installation

### Homebrew (recommended)

```bash
brew tap zh1C/lazybrew
brew install lazybrew
```

### Go Install

```bash
go install github.com/zh1C/lazybrew@latest
```

### Build from Source

```bash
git clone https://github.com/zh1C/lazybrew.git
cd lazybrew
go build -o lazybrew .
```

## Upgrade

```bash
brew update && brew upgrade lazybrew
```

## Usage

```bash
lazybrew
```
